# Mini Profile Page

A responsive React + Vite exercise demonstrating component composition, props, and CSS styling.

## Components
* **Header** – Centered, bold page title (`My Profile Page`).
* **ProfileCard** – Displays a uniform round avatar, bold name, description, and an action button inside a styled card.
* **Button** – Reusable button with dynamic color styling by role (`Friend` = green, `Teacher` = blue, `Student` = purple), plus hover and focus states.
* **Footer** – Centered footer text (`© 2025 My App`).

## Layout
* **Mobile:** Single-column stack.
* **Desktop:** 2-column responsive grid.
